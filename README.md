# 昌荣的作品集

线上地址：https://changrong996-droid.github.io

## 怎么添加新作品

1. 在 `works/` 下新建一个文件夹，比如 `works/my-new-game/`，把作品的 `index.html`（及相关资源）放进去。
2. 在首页 `index.html` 的 `.grid` 里加一张卡片，链接指向 `works/my-new-game/`。
3. 提交并推送，GitHub Pages 会自动更新（一般 1 分钟内生效）。
