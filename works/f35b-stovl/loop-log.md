## 一屏适配 · 2026-10-13 08:10（北京时间）· 用户需求
- 需求：页面随视口自适应，所有内容一屏放下、无纵向滚动条；图号/图注与说明可缩小、可折叠。
- 备份：backup/fit-viewport/（两页 HTML + 全部源码）。
- 改动（新增 fit.css、fit.js，两个 build 脚本拼入；model/detail/live*.js 未改，时间线、读数、机体几何、WebGL 挂点不变）：
  1. 页面 100vh（优先 100dvh），html/body overflow 隐藏；图卡 flex 纵向排布。
  2. 四角标签改为一行紧凑标题行（图号 · 标题 … 操作提示 · 实时读数）。
  3. 舞台放进 `.f35-box`（container-type: size），宽度 = min(100cqw, 160cqh)，始终 1280:800，SVG 与 WebGL 画布同框对位；不支持容器单位时 fit.js 用脚本算宽。ResizeObserver 在舞台尺寸变化时触发 resize 让渲染/画布重算。
  4. 读数条、控件压紧；跟拍版小地图与仰视小窗改为按舞台宽度比例（clamp）缩放。
  5. 图例 + 图注长段 + 操作说明移入默认收起的 `<details>`「说明」（控件行最右），展开为浮层：桌面浮在图形区下部、手机可占用图卡上方空白，不推动布局；Esc 或点外部收起；舞台 aria-describedby 指向图注。
  6. 手机（≤700px）：堆叠布局，舞台沿用 128% 放大并在图形区内裁切，读数 3×2 网格，整组内容垂直居中；隐藏键盘提示（说明里有）。
  7. 键盘聚焦框改为内收（outline-offset −2px），不再被图形区裁成两条竖线。
- 验证（无头 Chrome，两页 × 1440×900 / 1280×720 / 1920×1080 / 1024×768 / 390×844 × 说明收起/展开，共 20 组）：scrollHeight ≤ innerHeight 且 scrollWidth ≤ innerWidth 全部通过；舞台比例 1.600；画布与 SVG 矩形重合；无文字截断；控制台干净。另测：键盘（空格/1–3/←→/V）、Esc 收起、点外部收起、--reduced、--no-webgl 回退均正常且不滚动。尾焰与喷口对位肉眼确认。结果 shots/fit/scroll-check.json，截图 shots/fit/，拼图 shots/fit-viewport.png。
